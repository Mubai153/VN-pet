# VN 角色与两种桌宠

VN 是两种桌宠共用的角色。术语区分独立运行的 Windows 程序与供 Codex 播放的角色素材，以及素材从探索到交付的阶段。

## Language

**VN**：桌宠角色名称，外观辨识特征来自选定的像素形象及参考素材。
_Avoid_：用“VN”单独表示某个程序、文件夹或素材包格式。

**VN Windows 桌宠**：独立运行的 Windows 桌面陪伴程序，提供桌面互动、设置与主动陪伴。
_Avoid_：Codex Pet、自定义 Codex 素材包。

**VN Codex Pet**：供 Codex 展示和播放的 VN 角色素材，由 Codex 驱动动作与注视。
_Avoid_：用 Windows 桌宠或 VN 程序指代这些素材。

**素材包**：可以独立安装的角色配置与完整图集，也可随附说明和预览。

**设计版本**：角色形象与动作方案的一次明确修订，例如 A3 v3。

**图集契约版本**：消费者解释图集布局的格式版本，与设计版本分别演进。

**主形象**：已确认并用于约束后续动作中人物身份、比例和画法的基准形象。

**视觉原型**：用于比较外观和动作设计选择的临时样例，尚不等于正式成品。

**制作素材**：支撑生成、组装或审查的输入和中间结果。

**正式成品**：已经过素材验收、可独立交付使用的完整素材包。

**人物辨识度**：角色在不同造型和动作下仍能被认作同一人物的外观特征。

**头身比**：完整身高与头部高度的比例，用来比较头部辨识度和身体表达空间。

**任务状态**：Codex 需要向用户传达的任务进展或需关注的情形。

**动作表现**：角色用表情、姿态和连续运动表达任务状态或互动的方式。

**注视方向**：角色注意力朝向的位置，由眼睛、头部及必要的身体跟随表达。

**额度联动**：根据真实可用额度的变化自动切换角色外观或动作的行为。
