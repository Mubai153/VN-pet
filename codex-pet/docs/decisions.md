# VN Codex Pet 重要决策

更新日期：2026-09-08。当前正式成品为 [A3 v3](../packages/vn-a3-v3/README.md)，9 组动作与 16 个方向已按 D24 获用户验收。主形象采用 D21 选定的双眼校准版。B3 暂停；旧 A3 包保留在本地归档，新版未安装到本机。

## 当前有效范围

- 交付 Codex 素材包；Windows 桌宠的程序功能和目录结构独立维护。
- 保留 VN 的像素风、完整身体、眼镜及红色连帽衫；用表情和肢体表达状态，不加额外道具或额度联动。
- A3 v3 使用双眼校准、瞳孔外移前的主形象；旧 A3 v2 的验收不能替代新版验收。
- 原计划包含 A3 与 B3 两套独立 pet；B3 暂停并不等于取消，也不自动恢复制作。
- 显示名称暂用“VN · 圆润版”，最终名称仍未单独确认。本版按“仅打包，不覆盖旧包”完成，安装是独立后续操作。

## 决策沿革

以下按发生顺序保留 D1–D24。表中的“本轮”“当前”指作出该决策时的阶段；后续明确决策优先。D15、D16 对应旧 A3，D17 起进入新脸修订，D20 的瞳孔外移已由 D21 撤回，D24 完成了 D23 要求的新版验收。

| --- | --- | --- |
| D1 / Q1 | 首版只交付 Codex 桌宠包；本次不扩展或修改现有独立桌宠程序。 | 用户选择“只做 Codex 桌宠包”。 |
| D2 / Q2 | 基于现有素材与参考照片，保留 VN 的像素风和人物辨识度。 | 用户对 Q2 的明确补充；其中“任务辨识度”按上下文指人物辨识度。 |

| D4 / Q5 | 首版做好原生状态动作，额度联动暂不纳入；手动切换的吃饱版本也未获选。 | 用户选择“首版做好原生状态动作，额度联动暂不纳入”。 |

| D15 | A3 第二版精修通过主形象确认，后续 A3 动作以该图为身份、比例和画法基准。 | 用户对“这版 A3 可以作为正式主形象吗？”明确回复“确认”。 |
| D16 | A3 的 9 组标准动作与 16 个注视方向通过用户验收，允许进入 A3 正式组装、验证和打包。 | 用户对动作预览确认问题回复“确认”。 |
