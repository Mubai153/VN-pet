# VN Codex Pet A3 v3 制作规格

版本：2026-09-08。9 组动作与 16 个方向已获用户验收；正式文件见[成品目录](../../packages/vn-a3-v3/README.md)，验收状态和哈希见[发布记录](../../releases/vn-a3-v3.json)。旧包保留在本地归档，新版未安装。

## 形象基准与范围

唯一主形象为 [A3 双眼校准版](master.png)。使用瞳孔外移前的版本。真人照片只辅助理解转头后的结构，不再次重塑已经选定的正面脸。

本轮完成 A3 的 Codex v2 桌宠方案，B3 暂停。沿用已确认的 9 组原生动作和 16 个注视方向，不增加道具、额外状态或额度联动，不修改现有独立桌宠程序。旧 A3 动画包仅作为动作节奏的历史参考，不作为新身份的脸部来源；新包另行制作、审阅与交付。

人物气质保持亲切、专注、自然。脸部保留真人特征，状态主要通过肩膀、手臂、重心与头部姿态表达。此前选择的活泼动作幅度继续保留，避免通过放大眼睛、夸张眉毛或咧嘴来增强表现。

## 固定的视觉特征

| 部位 | 固定要求 | 动画允许的变化 |
| --- | --- | --- |
| 头部和身体 | 沿用选定图的实际比例、头宽、肩宽与四肢长度，不为凑“几头身”标签重塑身体。 | 屈膝、抬手、身体小幅起伏；姿态改变不伴随整体缩放。 |
| 眼睛 | 正面保留校准后的窄长眼型、开合、瞳孔位置和左右关系。 | 眨眼与成对注视；转头时允许合理透视差异，不能出现无原因的大小眼或视线分叉。 |
| 眼镜 | 细而横向较扁的圆角矩形，镜桥与鼻梁位置稳定。 | 随头部转向改变透视；镜框不能压住一只眼睛，也不能独立漂移。 |
| 面颊、鼻子、下巴 | 保留当前下半脸宽度、圆缓下巴及自然鼻部体量。 | 随表情作有限变化，不缩鼻、不削尖下巴，不强化鼻头亮斑。 |
| 嘴部 | 当前轻微闭口微笑与唇形是默认表情。 | 本方案建议所有动作先采用闭口表情：专注时稍收嘴角，招手时微扬，受阻时放平。不增加露齿笑。 |
| 头发和眉毛 | 保留当前蓬松黑发、刘海、露额空隙与眉形。 | 刘海可随起伏作极轻变化，不能左右交换偏分或忽然增加发量。 |
| 服装和肤色 | 红色连帽衫、深色裤子、鞋子保持一致；自然肤色与现有明暗关系固定。 | 必要的关节褶皱与遮挡变化；不产生橙黄肤色漂移、换鞋、增标识等变化。 |

全程闭口是针对新版相似度提出的制作建议，尚不是用户新增的永久限制。若后续确需露齿，先单独审查关键帧。

## 9 组动作

以下帧数沿用本机已核验的 v2 契约。幅度是原生 192×208 单格下的初始制作目标，最终以自然、可读、无裁切为准。

| 状态 | 帧数 | 关键姿态与过程 | 表情及区分点 |
| --- | ---: | --- | --- |
| 空闲 `idle` | 6 | 稳定站立 → 轻微吸气 → 上眼睑下降 → 闭眼 → 睁眼 → 回到原姿。脚底不动，肩胸呼吸幅度约 1–2 px。 | 保持小幅闭口微笑。眨眼由眼睑闭合表达，眼镜不动，瞳孔不在每帧漂移。 |
| 向右移动 `running-right` | 8 | 右向小跑的两次交替步态：触地、承重、经过、另一脚触地，再完成另一半周期。身体轻微前倾，起伏约 2–4 px。 | 头与行进方向一致，双臂随步伐交替。鞋子尺寸稳定、步态连续。 |
| 向左移动 `running-left` | 8 | 与右向同节奏的左向小跑，单独绘制以保留发型与人物特征。 | 不直接翻转整张图；左右动作的活力和角色大小相同。 |
| 打招呼 `waving` | 4 | 手臂抬至头侧准备 → 张掌高举 → 手腕小幅挥动 → 收回至准备姿态。动作循环应自然。 | 闭口嘴角略扬，肩膀轻提。手掌完整、手指简洁；挥手靠肢体表达，不画挥动符号。 |
| 跳跃 `jumping` | 5 | 屈膝蓄力 → 双脚离地 → 最高点 → 回落 → 屈膝落地。最高点初始约抬高 8–12 px。 | 保持脸部形状，手臂低于头顶随动。全程同一尺度，不因抬手或跳高自动缩小人物。 |
| 受阻 `failed` | 8 | 轻停顿 → 嘴角放平 → 低头 → 肩膀下沉 → 稍弯身 → 短暂停留 → 稍抬头 → 回到可循环姿态。 | 轻微失落、正在等待解决问题；不做痛哭或极端悲伤，不加眼泪、叉号等效果。 |
| 等待输入 `waiting` | 6 | 双手离开身侧 → 掌心朝上 → 小幅摊手 → 轻耸肩或小幅歪头 → 放松 → 回到询问姿态。 | 期待回应，视线朝用户。比空闲更明确，比受阻更开放；不靠放大双眼表现疑问。 |
| 工作中 `running` | 6 | 略前倾 → 固定一只手移到下巴附近 → 轻触下巴 → 小幅思考停顿 → 轻微点头 → 回到起始姿态。 | 眉眼专注、嘴角略收。思考手全程保持同侧，避免旧素材中的突然换手；双脚稳定，不表现为跑步。 |
| 查看结果 `review` | 6 | 双臂收拢 → 抱臂 → 轻微低头审视 → 稍抬眼 → 点头 → 回到抱臂姿态。 | 平静确认结果。与工作中的摸下巴、等待中的摊手明显区分；不添加纸张或放大镜。 |

标准动作共 57 帧。四肢的清晰轮廓优先于细碎手指、衣褶或高光。相邻状态切换时不强求每一帧站姿相同，但必须保持头部体量、肤色和身材一致。

## 注视与 16 个方向

默认正面使用已选主形象的视线，不再外移瞳孔。注视时两眼共同朝目标方向移动，并由头部轻微转向、抬头或低头补足方向信息；不能只移动一只瞳孔。

头部左右转向初始约 15–25°，仰俯幅度更小；这些是造型参考，不将画布角度直接当作头部旋转角。必要时增加转头幅度，让左右、上下在原生尺寸下明确可辨。腰部以下稳定，禁止旋转整个人物来模拟注视。

| 方向族 | 方向序列 | 核心可读特征 |
| --- | --- | --- |
| 正上至右上 | 0°、22.5°、45°、67.5° | 从抬下巴、双眼上望，平顺增加向右的面部转向。 |
| 正右至右下 | 90°、112.5°、135°、157.5° | 鼻尖及两眼共同指向右侧，逐步收下巴、显露头顶；靠近 180° 时减少右转。 |
| 正下至左下 | 180°、202.5°、225°、247.5° | 正下保持鼻梁居中；逐步增加左向面部转向，再减弱俯视。 |
| 正左至左上 | 270°、292.5°、315°、337.5° | 从明确左向逐步仰视，同时减小左转；337.5° 应接近正上姿态，避免回到 0° 时突然转头。 |

0° 表示向上，不是中立。无明确注视向量时回到普通正面姿态。16 个方向是连续的顺时针姿态族，不能把四张朝向重复复制来充数，也不强求转头后的双眼仍是完全镜像。

## 播放与交互边界

当前制作采用已核验的原生节奏：空闲 1100 ms、左右移动各 1060 ms、挥手 700 ms、跳跃 840 ms、受阻 1220 ms、等待 1010 ms、工作 820 ms、查看结果 1030 ms。逐帧时长保存在[包内预览](../../packages/vn-a3-v3/preview.html)的 `states` 定义中。这些用于素材制作和审查，实际触发、重复方式和状态优先级由 Codex 控制。

本方案交付图集与配置，不承诺通过素材包新增点击菜单、喂食、额度读取、定时提醒或自定义状态机。预览页可提供动作切换、暂停、逐帧、深浅背景与鼠标注视测试，便于审查素材。

## 制作顺序与验收

1. **固定中立单格。** 从已选主形象制作干净的透明基准单格，在 192×208 下检查双眼、唇形和镜框可读性；为挥手及跳跃留足边距。固定共享缩放比例与脚底位置，之后不按每一帧的外接框自动缩放。
2. **先验证最容易变脸的动作。** 先完成空闲与打招呼，检查眨眼、高举手时脸型与身材是否稳定。若产生大小眼、尖下巴或笑脸模板漂移，在扩展其他动作前修正。
3. **补齐标准动作。** 依次完善思考、抱臂、摊手、受阻、小跳和左右移动，逐行检查周期、尺度和手脚连接。沿用已确认的动作含义，全部使用新主形象生成，不给旧动画简单贴新脸。
4. **制作注视族。** 先核对上、右、下、左四个方向，再生成前八方向与后八方向两条完整素材；后一条参考前一条，重点检查两行交界及最后回到正上的过渡。
5. **交付素材预览。** 展示全部动作、方向、逐帧对照和原生尺寸播放；特别检查眨眼睁开后是否恢复同一眼型、转头是否产生视线分叉、挥手是否拉长身体、跳跃是否突然缩小。
6. **素材确认后打包。** 组装透明 v2 图集，统一处理边缘并完成尺寸、空格、裁切、方向与视觉检查。主形象相似度与动作观感由用户最终验收；安装另按用户明确要求执行。

视觉验收分两层：正面帧对照主形象，确认五官关系不漂移；运动帧在原生尺寸下检查状态是否可读、转向是否正确、循环是否自然。方向检查结合独立无标签辨认和有序循环，不仅依靠图集尺寸通过。
